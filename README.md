**Omnifood** is a modern, fully responsive food delivery landing page designed with:

📱 Mobile-first responsiveness  
🔍 SEO-friendly structure  
🧩 Clean & scalable layout  

It delivers a **premium product-level UI experience** using only front-end technologies.
